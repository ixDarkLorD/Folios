# Folios website

Guide books for Minecraft mods, written as JSON in a resource pack.

This `docs` branch of [ixDarkLorD/Folios](https://github.com/ixDarkLorD/Folios) holds the Folios website: its homepage,
documentation and license, at **https://ixdarklord.github.io/Folios/**. The mod's code is on the version branches
(`26.1.2`, `26.2`, `26.3`, `1.21-1.21.1`, `1.20.1`), and bugs and ideas go to
[Issues](https://github.com/ixDarkLorD/Folios/issues).

- Download: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/folios) · [Modrinth](https://modrinth.com/mod/folios)
- License: [Folios License](https://ixdarklord.github.io/Folios/license/)

The site is built with [Zensical](https://zensical.org): `pip install zensical`, then `zensical serve` to preview and
`zensical build` to build. Pushing to this branch builds it and publishes it through GitHub Pages.
