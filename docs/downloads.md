# Downloads

## Folios

Download Folios only from its official pages:

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/folios){ .md-button .md-button--primary }
[Modrinth](https://modrinth.com/mod/folios){ .md-button .md-button--primary }

Folios needs [CoolCatLib](https://modrinth.com/mod/coolcatlib), and Fabric API on Fabric.

## The book template

A complete example resource pack: a book with categories, entries and every kind of page, and a README of every key.
Copy it, rename `mymod` and `my_guide`, and start writing. It is public domain (CC0): use it however you like.

[Download the template](assets/folios-book-template.zip){ .md-button }

Then follow [Your first book](docs/getting-started.md).
